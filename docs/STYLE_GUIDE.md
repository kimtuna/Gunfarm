# STYLE_GUIDE — 캐릭터 그림체 기준

> `[DESIGN]` 태그 항목일 때만 읽는다. `[BUILD]`는 그림을 만들지 않으니 필요 없다.

**아직 비어 있다.** 참고 이미지(`design_reference/`)와 구체적인 비율/음영/외곽선/팔레트
기준은 첫 `[DESIGN]` 항목을 실제로 진행할 때 사람과 함께 채우기로 했다.

그때까지 `[DESIGN]` 항목의 합격 기준은 `DESIGN.md`의 다음 절을 그대로 따른다:
- "그래픽 파이프라인" — 이질감이 없는가(어울림 + 자연스러움)
- "캐릭터 애니메이션 (중요 규칙 — 절대 되돌리지 말 것)"
- "아이템/오브젝트 크기 표준"

이 파일이 비어 있는 상태에서 그림체 자체에 대한 판단이 필요해지면, 임의로 정하지 말고
`STATUS.md`의 "막힌 것 / 보류"에 남기고 사람의 지시를 기다린다.
