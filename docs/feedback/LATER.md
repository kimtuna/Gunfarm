# LATER — 나중에 할 것

> **이 파일은 작업 큐가 아니다.** 루프(`loop.sh`)는 `INBOX.md` 만 읽으므로, 여기 적힌
> 것은 절대 자동으로 실행되지 않는다. "지금은 안 하지만 잊고 싶지 않은 것"을 사람이
> 적어두는 곳이고, 대시보드(`docs/index.html`)에 그대로 표시된다.
>
> 실제로 만들 때가 되면 이 줄을 `INBOX.md` 에 새 번호의 `- [ ] #N [BUILD|DESIGN] ...`
> 항목으로 옮겨 적는다(여기서 지우고 INBOX 로 이사시킨다).
>
> 형식: `- <한 줄 요약> — <왜 나중인지 / 무엇을 정해야 하는지>`

## 목록

- **맵에 마크(표식) 찍기** — M 맵 위에 플레이어가 직접 표식을 남기고 지우는 기능.
  (2026-09-07 사람이 "나중에 할 것"으로 넣음.) 정해야 할 것: 표식 종류가 몇 개인지,
  이름/메모를 붙일 수 있는지, 슬롯 저장에 어떻게 들어가는지(탐험 기록과 같은 자리),
  그리고 **멀티에서 표식을 팀원과 공유하는지** — 공유한다면 `DESIGN.md` 「맵 (M)」의
  "맵에 다른 플레이어를 표시하지 않는다"와 어디까지 어긋나는지 먼저 판단해야 한다.

- **도구 6종을 차례대로 추가** — 총(사냥) / 곡괭이(채광) / 낫(채집·수확) / 괭이(밭 일구기) /
  물뿌리개(물 주기) / 낚싯대(낚시). **도끼(INBOX #24)가 파이프라인을 세운 뒤** 같은
  방식으로 하나씩 올린다 — 절차는 `DESIGN.md` 「새 도구를 추가하는 절차」에 고정돼 있고,
  도구 하나에 [DESIGN] 한 바퀴 + [BUILD] 한 바퀴다.
- **밭 시스템(농사)** — 괭이·물뿌리개가 실제로 쓸 밭 타일 상태(일궈짐 / 물 준 상태 /
  마름)와 작물 성장. 규칙은 `DESIGN.md` 「생활 스킬 — 생산 계열」에 스타듀식으로 정해뒀고,
  작물별 성장 일수·계절 제한은 아직 범위 밖이다.
