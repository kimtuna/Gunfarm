# LATER — 나중에 할 것

> **이 파일은 작업 큐가 아니다.** 루프(`loop.sh`)는 `docs/INBOX.md` 만 읽으므로, 여기 적힌
> 것은 절대 자동으로 실행되지 않는다. "지금은 안 하지만 잊고 싶지 않은 것"을 사람이
> 적어두는 곳이고, 대시보드(`docs/index.html`)에 그대로 표시된다.
>
> 실제로 만들 때가 되면 이 줄을 `docs/INBOX.md` 에 새 번호의 `- [ ] #N [BUILD|DESIGN] ...`
> 항목으로 옮겨 적는다(여기서 지우고 INBOX 로 이사시킨다).
>
> 형식: `- <한 줄 요약> — <왜 나중인지 / 무엇을 정해야 하는지>`

## 목록

- **맵에 마크(표식) 찍기** — M 맵 위에 플레이어가 직접 표식을 남기고 지우는 기능.
  (2026-09-07 사람이 "나중에 할 것"으로 넣음.) 정해야 할 것: 표식 종류가 몇 개인지,
  이름/메모를 붙일 수 있는지, 슬롯 저장에 어떻게 들어가는지(탐험 기록과 같은 자리),
  그리고 **멀티에서 표식을 팀원과 공유하는지** — 공유한다면 `DESIGN.md` 「맵 (M)」의
  "맵에 다른 플레이어를 표시하지 않는다"와 어디까지 어긋나는지 먼저 판단해야 한다.

- **도구의 2단계 — 실제 효과** (벌목 / 채광 / 사냥 / 낚시 / 밭일구기). 도구 1단계(그림과
  모션)는 INBOX #24~#31 로 끝나지만, 좌클릭이 실제로 무언가를 바꾸는 것은 **캘 대상이
  월드에 생긴 뒤**다. `DESIGN.md` 「새 도구를 추가하는 절차」의 2단계 — **도구가 아니라
  대상을 기준으로 묶인다**: 나무를 만드는 바퀴가 벌목까지, 광맥을 만드는 바퀴가 채광까지
  같이 붙인다. 그래서 다음에 필요한 것은 도구 항목이 아니라 **자원 오브젝트를 월드에
  놓는 항목**이다.
- **밭 시스템(농사)** — 괭이·물뿌리개가 실제로 쓸 밭 타일 상태(일궈짐 / 물 준 상태 /
  마름)와 작물 성장. 규칙은 `DESIGN.md` 「생활 스킬 — 생산 계열」에 정해뒀고,
  작물별 성장 일수·계절 제한은 아직 범위 밖이다.

- **플레이어 체력 + 죽음 + 리스폰 + 데스드롭 상자** — 규칙은 `DESIGN.md` 「체력 / 죽음 /
  리스폰」에 2026-09-07 로 다 정해져 있다(체력 100 / 스폰 좌표 리스폰 / 상자 30분 /
  **열면 타이머 멈춤**). **먼저 있어야 하는 것**: 플레이어가 데미지를 받을 경로 —
  즉 총알(투사체)이 실제로 날아가고 맞는 것. 그게 없으면 죽을 방법이 없어서 검증이
  안 된다. 순서는 총알 → 체력·죽음 → 데스드롭 상자다.
- **침대** — 설치하면 리스폰 지점이 바뀐다(`DESIGN.md` 「건축 / 방 시스템」). 건축
  시스템 자체가 아직 없으므로 그것과 같이 온다.
- **월드 설정 화면** — 지금 「설정」에는 그래픽 옵션만 있다. 월드(슬롯)에 저장되는
  설정을 두는 자리이고, 첫 항목은 데스드롭 상자 타이머다. 데스드롭 상자를 만드는
  바퀴가 같이 만드는 게 자연스럽다.

- **낚시 던지기(2단계)** — 좌클릭으로 던지고, 거리는 마우스 커서까지로 조절하며(최소는
  바로 앞, **최대는 화면 안**), **찌가 떨어진 칸이 물이어야** 낚시가 시작된다. 규칙은
  `DESIGN.md` 「생활 스킬 — 채집 계열」의 낚시 항목에 다 있다. 정해야 할 것: 최대 거리
  수치, 찌를 던지고 무는 것을 기다리는 시간, 무엇이 잡히는지.
- **물의 종류(서식지)** — 지금 지형은 땅/바다 2종뿐이라 **서식지를 나눌 기준이 없다.**
  민물·깊은 바다·동굴 물 같은 구분이 생겨야 "서식지에 따라 잡히는 물고기가 다르다"가
  성립한다. **물고기 종류를 먼저 만들지 말 것** — 나눌 기준 없이 종류만 늘리면 전부
  같은 물에서 나온다. 지형 확장 → 서식지 → 물고기 순이다.

- **여는 좌클릭과 도구를 쓰는 좌클릭을 한 곳으로 모으기** (원래 INBOX #41, 2026-09-07 에
  여기로 옮김). 지금 열 수 있는 것은 데스드롭 상자 하나뿐이라 **미리 만들면 껍데기만
  늘어난다.** 상자·제작대처럼 「여는 것」이 둘 이상이 되는 바퀴가 가져간다.
