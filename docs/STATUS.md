## 만든 것

- **`game/scripts/character_palettes.gd`** — **자동 생성 파일**(손으로 고치지 말 것).
  `gen_character.py` 의 `export_palettes()` 가 만든다. 피부 5 / 머리 6 / 옷 6 각각의
  재질별 4단계 램프 색이 들어 있다. **`make_ramp()` 를 GDScript 로 옮겨 적지 않기
  위해** 생성기가 계산한 값을 그대로 내려보내는 쪽을 골랐다 — 옮겨 적으면 언젠가
  반드시 어긋난다. 밴드가 항목마다 독립이라 5×6×6 이 아니라 5+6+6 줄이면 된다.
- **`game/scripts/character_sprite.gd`** — 팔레트 교체. 기준색 PNG 의 픽셀 색을
  **기준 램프 색 → 고른 색의 램프 색**으로 통째로 갈아끼운다(형태·알파 불변).
  `get_pixel()` 로 도는 대신 바이트 배열을 훑고, 색별로 결과를 캐시한다.
- **`game/assets/sprites/player_idle_{short,bob,long,ponytail}.png`** — 머리모양마다
  시트 한 장. **`player_idle.png` 은 `player_idle_short.png` 으로 이름만 바뀌었고
  내용은 1비트도 안 달라졌다**(#8/#9 가 합격시킨 그림 그대로 — 해시로 확인).
- **`gen_character.py` 의 `HAIR_STYLES`** — 머리모양 4종을 **파라미터 표 하나**로
  정의한다(옆머리 깊이 / 흘러내리는 단 길이·폭 / 뒷머리 길이 / 앞머리 결 / 꼬리).
  형태 코드는 하나고 숫자만 다르다 — 그래야 넷이 같은 캐릭터로 보인다.
  새 도형 둘: `_fall_shape()`(아래로 좁아지고 끝이 둥근 기둥), `_tail()`(위아래가
  뾰족한 타원).
- **`game/qa/qa_character_sprite.gd`** — 팔레트 교체 자체 QA. 램프 표 ↔ 선택지
  동기화 / 시트 4종 존재 / 기준색 램프 20색이 서로 안 겹치는지 / 바꿔치기가 빠짐없이
  되는지 / 알파 불변 / 선택지끼리 결과가 다른지. 극단 색 조합 6벌 캡처도 남긴다.
- `appearance_preview.gd` 를 색 사각형에서 **실제 시트**로 갈아끼웠다 — 앞모습 6배
  하나 + 나머지 세 방향 2배. 뒷모습이 없으면 「묶은머리」 차이를 볼 수 없다.
- `player_frames.gd` 에 `sheet_path(모션, 머리모양)` — 시트 경로 규칙을 아는 유일한 곳.
- `qa_player_sprite.gd` 를 머리모양 4종 전부 보도록 확장(캡처도 4×4 격자).
- `qa_sprite_check.py`: 시트별 스펙 + 「재질」 검사 추가.

## 스스로 판단해서 고친 부분

- **`player_idle.png` 을 `player_idle_short.png` 으로 이름을 바꿨다.** 지시에 없지만,
  머리모양 4종이 생기는 순간 `player_idle.png`(짧은머리) + `player_idle_bob.png` 식의
  비대칭 이름이 남는다. 걷기(#13)에서 시트가 4장 더 생기므로 지금 통일하는 게 싸다.
- **램프 맨 위에 한계(`CEIL = 242`)를 넣었다.** 램프 배율이 기준색(검정 머리)에 맞춰
  잡혀 있어서 금발·은발에 곱하면 목표 명도가 255 를 넘고, 밝은면이 **순백 덩어리**로
  뭉개져 금발과 은발이 하이라이트만 보면 똑같아졌다. 기준색(밝은 피부 240.7)은
  한계 아래라 **기존 그림은 한 픽셀도 안 바뀐다**.
- **`qa_sprite_check.py` 의 「대비」에서 "안 맞닿는 재질쌍"을 불합격이 아니라 건너뛰기로
  바꿨다.** 긴 머리는 목을 덮어서 피부와 셔츠가 어디서도 안 닿는다 — 그건 불합격이
  아니다. 대신 **「재질」 검사를 새로 넣어** 재질이 통째로 사라진 그림이 조용히
  통과하는 구멍을 막았다.
- **머리 길이가 다른 시트는 「평균명도/어두운비율/채도」만 시트별로 잡았다.** 기준색
  머리가 검정(무채색)이라 길수록 실제로 더 어둡고 탁하다. 나머지 검사는 안 늦췄다.
- 미리보기에 **나머지 세 방향을 작게 같이** 띄웠다. 앞모습만으로는 「묶은머리」와
  「짧은머리」가 거의 같아 보여서, 고른 것이 뭔지 확인할 방법이 없다.
- 이름을 한 글자 칠 때마다 화면이 새로고침되므로, 미리보기가 **정말 바뀐 때만**
  시트를 다시 칠하게 막았다(픽셀 1만 8천 개를 도는 작업이다).

## 어려움 / 에러와 해결

- **묶은머리 앞모습이 바가지머리로 나왔다.** 꼬리를 머리 실루엣 **안**에 뒀더니 같은
  색이라 앞머리와 한 덩어리가 됐다. 실루엣 밖으로 빼서 해결 → STYLE_GUIDE 에 남겼다.
- **단발이 긴머리와 구별이 안 됐다.** 길이만 줄였더니 이번엔 짧은머리와 붙었다.
  길이가 아니라 **폭(부피)** 으로 가르는 쪽이 맞았다(`fw`).
- **뒷모습 묶은머리가 긴머리처럼 보였다.** 꼬리 폭이 머리와 비슷해 한 덩어리로
  이어졌다 — 꼬리를 머리보다 확실히 좁게(2.15) 하고 시작점을 머리 안쪽으로 내렸다.
- `qa_sprite_check.py` 가 「대비」 리포트를 찍다가 `None` 포맷팅으로 죽었다(위 참고).
- 팔레트 교체 QA 가 "선택지끼리 결과가 같다"로 거짓 실패했다 — 항목마다 **기준색
  선택지 하나는 아무것도 안 바뀌는 게 정상**이라, 비교를 같은 항목 안으로 좁혔다.
