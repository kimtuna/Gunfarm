## 정한 것: `*.gd.uid` 는 **커밋한다**

결정과 근거는 `CLAUDE.md` 「git」 절에 적어뒀다(매 세션이 읽는 파일이라 거기가 제자리다).
`.gitignore` 에도 "여기 넣지 않는다"고 이유와 함께 박아둬서, 다음 바퀴가 `git status` 가
지저분하다는 이유로 무심코 무시 규칙을 추가하지 않게 했다.

무시하는 쪽이 아니라 커밋하는 쪽을 고른 근거는 **실제로 실험해서 확인한 사실**이다.
버려도 되는 임시 프로젝트를 만들어 uid 를 지우고 `--import` 를 다시 돌려봤다:

- **uid 는 `res://` 경로의 해시다 — 무작위가 아니다.** 같은 경로면 uid 파일을 지우고
  다시 임포트해도, 프로젝트를 다른 절대 경로로 통째로 복사해도 **같은 값**이 나온다.
  다른 경로면 다른 값이 나온다. (Godot 4.7 기준. 4.4 때는 무작위였다고 알려져 있으니
  버전을 올릴 때 이 전제를 다시 확인할 것.)
- 그래서 커밋해도 **diff 가 지저분해지지 않는다** — 한 줄짜리 값이 한 번 생기면 다시는
  안 바뀐다. 새 스크립트당 한 줄이 늘 뿐이다. "커밋하면 노이즈가 는다"는 걱정은 근거가 없었다.
- 반대로 무시하면 **파일을 옮기거나 이름을 바꾼 순간 깨진다.** 이름을 바꿔도 에디터는
  기존 uid 를 유지하는데, uid 파일이 없는 새 클론에서는 새 경로의 해시로 다시 만들어져서
  씬에 저장된 `uid://` 참조와 어긋난다.
