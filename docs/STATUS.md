## 무엇을 「캐릭터의 색」으로 볼지 — 이번 바퀴가 정한 것

INBOX #59 가 세션 판단에 맡긴 자리다. **넓이로 잰다** — 몸 픽셀 하나하나가 풀과
명도로 갈리는지 세어서 갈리는 넓이가 몸의 몇 %인가를 본다.

| 후보 | 왜 안 골랐나 |
|---|---|
| 몸 평균 명도 | 잉크(19)와 하이라이트(251)를 같이 평균 낸 값이다 — **94.5** 라 풀(101)과 6.5 밖에 안 떨어져 **멀쩡한 그림이 불합격**한다(#59 가 이미 실측해둔 것) |
| 몸 명도의 중앙값 | 캐릭터의 **전부**가 풀과 갈리라는 요구가 된다. 옛 검사가 물었던 것은 셔츠 **한 벌**이었다 — 신발이 풀과 비슷한 명도인 것은 결함이 아니다 |
| 잉크·하이라이트 뺀 최빈색 몇 개 (#59 의 예시) | 램프가 4단계라 최빈색 순위가 몇 픽셀 차이로 뒤집힌다. 넓이로 세면 N 을 안 고르고도 같은 것을 묻는다 |

- **외곽선(잉크)은 뺀다.** 몸의 **15%** 를 차지하면서 어떤 배경과도 늘 갈리는 색이라,
  넣어두면 어떤 그림이든 15% 를 공짜로 얻는다.
- **잉크색을 상수로 적지 않았다** — `docs/CHARACTER.md` 8절(*"팔레트가 ComfyUI 그림에서
  나오므로 색을 적어두면 그림을 바꾼 바퀴가 반드시 잊는다"*) 그대로, **실루엣
  테두리에서 가장 많이 쓰인 색**으로 찾는다. 22장의 테두리는 실제로 `#1a0f18`
  **한 색이었다**(테두리 픽셀의 100%).
- **하이라이트는 일부러 안 뺐다.** 평균과 달리 넓이 세기에서는 밝은 몇 픽셀이 값을
  끌고 다니지 않는다 — 넓이만큼만 센다.

**하한 40% 는 실측한 두 극단의 가운데다** (아래 실험 표): 지금 그림 60% ↔ 정말로
묻힌 그림 12%.

| 실험 | 갈리는 넓이 | 결과 |
|---|---|---|

- **값이 지형을 실제로 따라간다**: 풀 명도를 56 / 80 / 101 / 120 / 150 으로 놓고
  재면 48 / 50 / 60 / 69 / 75% 로 움직인다 — 캐릭터만 보는 값이 아니다.
