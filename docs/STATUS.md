## 만든 것

- **`game/tools/gen_terrain.py`** — 지형 생성기. 팔레트는 `gen_character.py` 의
  `make_ramp()` 를 **그대로 불러 쓴다**(램프 만드는 방식이 같아야 같은 그림으로
  보인다). 재질 5종 × 4단계: 풀 / 깊은바다 / 여울 / 물거품 / 땅쪽테두리.
- **`game/assets/sprites/terrain_tiles.png`** — 아트 16px 칸 **4096개** 한 장
  (1024×1024, 82KB). 칸 번호 =
  `무늬변주(0~7) × 512 + (중심이 땅이면 256) + 이웃 8칸의 땅 비트마스크`.
  **밑그림과 해안이 한 칸에 같이 구워져 있어** 그리는 쪽은 칸마다 그리기 한 번이면
  되고 반투명 오버레이를 겹치지 않는다.
- **`game/scripts/terrain_tiles.gd`** — 그 번호 규칙을 아는 **유일한 곳**(순수 클래스).
  좌표 해시 → 변주, 이웃 8칸 → 마스크, 번호 → 시트 사각형.
- **`game/scripts/terrain_palettes.gd`** — **자동 생성 파일**(손으로 고치지 말 것).
  `gen_terrain.py` 의 `export_palettes()` 가 만든다. 화면의 픽셀이 땅인지 바다인지
  판정하는 자체 QA 가 이 표를 쓴다.
- **`game/scripts/terrain_view.gd`** — 색 사각형 → 타일 스프라이트로 갈아끼웠다.
  화면에 들어오는 칸만 그리고, 지도 밖도 그냥 같이 돈다(`at()` 이 바다로 답한다).
- **`game/qa/qa_terrain_view.gd`** — 엔진 쪽 검증. 시트 규격 / **칸 번호 규칙이
  생성기와 같은지**(손으로 만든 작은 지도로 마스크를 직접 계산해 맞춰본다) / 변주가
  좌표마다 갈리는지 / 지형 한가운데 칸에 해안 색이 없는지 / 텍스처 필터.
  캡처 `61_terrain_with_player` 는 **해안 위에 캐릭터 4방향을 세운 것**이다.
- **`qa_sprite_check.py` 에 지형 갈래 추가**(스펙의 `kind`) — 규격/팔레트/**이음매**/
  변주/평균명도/채도/**캐릭터대비**.

## 스스로 판단해서 고친 부분

- **격자선을 뺐다.** 지시에 없지만 "인접한 같은 지형끼리 이어져 보여야 한다"와
  정면으로 부딪힌다(48px 마다 선이 그이면 이어질 수가 없다). DESIGN.md 가 "그림이
  생기면 이 스크립트를 갈아끼운다"고 미리 적어둔 자리라 판단해서 뺐고, 건축 격자는
  배치 미리보기로 그리면 된다고 DESIGN.md 에 적었다.
- **한 칸에 밑그림 + 해안을 같이 구웠다**(오버레이 두 장이 아니라). 땅이 바다 타일
  쪽으로 불거지는 자리에 밑그림이 없어서 풀을 그릴 수가 없기 때문이다.
- **해안선 흔들림을 땅이 커지는 쪽으로 치우치게 했다.** 충돌은 타일 단위라
  (`player_motion.gd`) 그림의 땅이 논리 타일보다 작아지면 **물 위를 걷는 것처럼**
  보인다. 반대쪽은 "못 밟는 물가"가 2px 남을 뿐이고 테두리·물거품에 가려진다.
- **지형 램프도 GDScript 로 내려보내는 파일을 만들었다**(`character_palettes.gd` 와
  같은 방식). `qa_world_entry.gd` 가 스크린샷의 픽셀을 땅/바다로 가르는데, 지형이
  스프라이트가 된 순간 "색 하나"가 아니라 램프 4단계가 되어 옛 판정이 깨졌다.
  색을 QA 에 손으로 베껴 적으면 반드시 어긋난다.
- `world_gen.gd` 의 타일 크기 주석이 아직 "아트 32px × 1.5배"였다(2026-09-06 정정
  이전 문구) — 실제로 16px 타일을 만들면서 같이 고쳤다.

## 어려움 / 에러와 해결

- **처음 만든 3×3 블록 방식이 벽지가 됐다.** 블록 하나를 심리스로 굽고 `x%3` 으로
  고르면 이음매는 완벽한데, 눈에 띄는 무늬가 화면 144px 마다 **정확히** 되풀이돼서
  풀밭이 벽지로 보였다. → 타일 하나가 스스로 감기게 만들고 **좌표 해시**로 변주를
  고르는 쪽으로 갈아엎었다(STYLE_GUIDE 6번에 남김).
- **노이즈 얼룩으로 바탕을 채운 후보는 전부 위장무늬였다.** 바탕은 기본 단계 한
  색으로 두고 획 몇 개만 얹는 쪽이 훨씬 낫다.
- **풀잎을 붙여서 부채꼴로 그렸더니 작은 삼각형(=멀리 있는 나무)으로 보였다.**
  잎 사이를 띄우니 풀로 읽혔다.
- **획 아래 그늘을 획 찍는 루프 안에서 같이 찍어 획이 1px 로 뭉개졌다**(다음 픽셀이
  앞 픽셀을 덮어씀). 그늘은 획을 다 찍은 뒤 따로 깐다.
- **`fbm()` 결과를 정규화하지 않아 해안선 흔들림이 3분의 1 토막 났다** — 심플렉스는
  이론 최대치까지 안 올라간다. 그래서 처음엔 "흔들었는데 왜 계단 그대로지?" 였다.
- **정규화한 뒤에는 반대로 레이스 장식이 됐다.** 잡음 주기가 타일 한 칸(16px)이라
  — 이웃 타일과 이어지려면 그래야 한다 — 곧게 뻗은 해안에 같은 물결이 48px 마다
  똑같이 되풀이됐다. → **잡음은 약하게(1.2px), 계단은 거리장을 흐려서(가우시안
  2.7) 뭉개는** 쪽으로 바꿨다. 해안의 변화는 이웃 배치(마스크)가 만든다.
- `qa_uid_files` 가 새 파일 4개를 "git 미추적"으로 잡았다 — 정상 동작이다(`git add`
  하고 다시 통과).
