## 정한 것: `*.import` 도 **커밋한다**

`.gd.uid` 와 같은 결론이지만 **근거는 더 강하다.** 결정과 근거는 `CLAUDE.md` 「git」 절에
적어뒀고(매 세션이 읽는 파일이라 거기가 제자리다), `.gitignore` 에도 "여기 넣지 않는다"고
이유와 함께 박아뒀다.

`.gd.uid` 때와 같은 방식으로 버려도 되는 임시 프로젝트를 만들어 실제로 확인했다:

- **`[remap]` 의 `uid`/`path` 는 `res://` 경로에서 결정된다.** `.import` 와 `.godot/` 를
  통째로 지우고 재임포트해도 같은 값이 나오고, 프로젝트를 다른 절대 경로로 복사해도
  같은 값이며, **그림 내용만 바꿔도 값은 그대로다.** 파일 이름을 바꿔야(=res:// 경로가
  달라져야) 값이 달라진다. 그래서 커밋해도 diff 가 지저분해지지 않는다.
- **결정적인 차이는 `[params]` 다 — 이건 경로에서 되살릴 수 없다.** 손으로 바꾼 임포트
  설정(압축 모드/밉맵 등)은 재임포트해도 유지되지만, `.import` 파일을 지우는 순간
  기본값으로 돌아갔다. 즉 무시하면 **새 클론마다 조용히 다른 설정으로 임포트된다** —
  도트 그래픽에서는 그림 품질이 직접 달라진다는 뜻이다.
- 저장소에는 이미 `game/icon.svg.import` 가 추적되고 있었다(프로젝트 템플릿에서 온 것).
  커밋하는 쪽으로 정한 것은 이미 있던 상태와도 일치한다.

## 자체 QA

`--headless --path game --script qa/qa_uid_files.gd` — **PASS 만 확인하고 끝내지 않았다.**
`game/assets/_qa_probe.png` 를 임시로 만들어 `--import` 를 돌린 뒤, 깨진 상태 5가지를
일부러 만들어서 전부 FAIL 로 잡히는 것까지 확인하고 원상복구했다:

1. `.import` 가 untracked → FAIL (규칙 3, 새로 추가한 것)
2. `.import` 를 치움 → "`.import` 없음" FAIL (규칙 1, 새로 추가한 것)
3. PNG 만 지우고 `.import` 를 남김 → "고아 `.import`" FAIL (규칙 2, 새로 추가한 것)
4. 기존 `.gd.uid` 를 치움 → FAIL (회귀 확인 — 스크립트를 다시 쓴 뒤에도 살아있는지)
5. 고아 `.gd.uid` 를 심음 → FAIL (회귀 확인)

원상복구 후 PASS (메타파일 22개: uid 21 + `icon.svg.import` 1). 프로브 PNG 는 지웠고
커밋에 들어가지 않는다 — 이번 항목은 규칙을 정하는 것이지 자산을 만드는 것이 아니다.
