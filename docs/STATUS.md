## 스스로 판단해서 고친 부분

- **반동을 코어의 틱 안에 넣지 않았다.** `player_motion` 은 든 **칸 번호**까지만 알고 그
  칸에 총이 있는지는 모른다(「서버 권위」) — 틱 안에서 깎으면 **도끼를 휘둘러도 조준이
  흐트러진다.** 그래서 `apply_recoil()` 을 밖으로 내고, 인벤토리를 가진 `world.gd` 가
  "이번 좌클릭이 실제로 총을 쐈다"를 확인한 뒤에 부른다.
- **총알에 노드를 하나씩 두지 않았다.** 바닥 아이템은 Y정렬 묶음에 들어가려고 그랬지만
  (INBOX #33), 총알은 지면에 놓인 물건이 아니라 **머리 위로 지나가는 것**이라 앞뒤를 가릴
  게 없다. `Entities`(Y정렬) 밖에 두었고, 그래서 `z_index` 가 정상으로 먹는다(YSort 안에서는
  무시된다 — `docs/GOTCHAS.md`). 조준선도 같은 이유로 밖에 있다.
- **연사 간격을 새로 만들지 않았다.** 도구 쓰기의 `USE_TICKS`(30틱 = 0.5초)가 이미
  「총기 스탯」의 초당 2발과 같은 값이라, 총알을 **쓰기가 시작된 틱**에 내보내는 것만으로
  간격이 저절로 지켜진다. 값을 두 군데 두면 어긋난다.
- **총알을 저장하지 않는다.** 0.9초면 사라지는 것이라 나갔다 들어와서 되살릴 값이 아니다
  (바닥 아이템과 다른 판단이고, 근거를 `DESIGN.md` 에 적었다).
- **한 걸음(12)을 속도와 따로 상수로 뒀다.** 지금 속도(900)면 한 틱이 15 라 벽을 못
  건너뛰지만, 나중에 속도만 올렸을 때 조용히 뚫리는 것을 막으려면 충돌 간격이 속도와
  분리돼 있어야 한다.
- **`hit_test` 를 함수가 아니라 꽂아 넣는 `Callable` 로 뒀다.** "자리만 남긴다"는 지시를
  상속 없이 지킬 수 있고, 동물을 만드는 바퀴가 한 줄만 꽂으면 된다. 자체 QA 가 그 자리가
  **실제로 불리는지**(그리고 한 걸음짜리 선분으로 불리는지) 확인한다.

## 어려움 / 에러와 해결

- **조준선을 부챗살 7줄로 그렸더니 "흐린 선"이 아니라 "빨간 선 일곱 개"로 보였다.**
  캡처를 눈으로 보고 알았다(검사는 통과했다 — 픽셀 수만 세면 살이 낱낱이 보이는 것을 못
  잡는다). 살을 겹칠 만큼 늘리면 이번엔 낱낱이 옅어져 아무것도 안 보인다. **진하기(심지)와
  폭(부채꼴)을 나눠 맡기는 쪽**으로 바꿔서 해결했다.
- **부채꼴 한 겹은 손전등 불빛처럼 가장자리가 딱 끊겼다.** 좁은 겹(1.0 / 0.66 / 0.33배)을
  포개서 가운데가 진하고 가장자리로 옅어지게 했다.
- **꼭짓점이 겹친 사각형은 엔진이 못 쪼갠다** — 정조준이 거의 다 모이면 부채꼴 폭이 0 에
  가까워져 `Invalid polygon data, triangulation failed` 가 프레임마다 났다. **검사는 그대로
  PASS 였다**(엔진 ERROR 는 `SCRIPT ERROR` 가 아니다) — 로그를 눈으로 보고 잡았고, 폭이
  1 미만이면 그 겹을 안 그리게 했다.
- **날아가는 총알이 검사에서 사라졌다.** 자체 QA 가 마우스를 화면 한가운데 기준으로 옮겼는데,
  **화면 한가운데는 플레이어 발밑이고 조준 기준점은 가슴**이라 5도쯤 아래로 겨눠지고 있었다.
  총알이 멀어질수록 아래로 벗어나 가로 띠 검사를 빠져나갔다. 마우스를 가슴 높이로 옮기고,
  **조준이 실제로 수평인지 검사를 하나 더 넣었다**(안 그러면 다음 사람이 같은 데 빠진다).
- **검사에 이가 있는지 다섯 가지로 확인했다** — 한 걸음을 타일보다 크게 / 지형에 안 막히게 /
  탄퍼짐이 정조준을 안 따라가게 / 반동 없애기 / 총이 아니어도 조준선 켜기. **다섯 다 FAIL
  했고** 되돌리니 PASS 했다.
- Godot 자체 QA **19개 전부 PASS**(엔진 ERROR 0건), 파이썬 그림 검사도 PASS. 캡처를 눈으로
  확인했다 — 또렷한 조준선 / 번진 조준선 / 도끼를 들면 사라진 것 / 총구를 막 떠난 총알 /
  0.12초 뒤 멀리 날아간 총알(그 사이 반동으로 흐려졌다가 다시 모이는 것까지 보인다).
