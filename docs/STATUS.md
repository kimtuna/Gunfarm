## 어려움 / 에러와 해결

- **아이콘이 처음엔 망치로 보였다.** 원인은 `capsule` 의 둥근 뚜껑 — 날 끝이 반원이면
  이 크기에서 도끼로 안 읽힌다. `wedge` 로 바꾸고 자루 각도(50/58/66/74도)와 날
  비율을 나란히 뽑아 비교해서 골랐다.
- **잘 나온 아이콘 후보를 칸 가운데로 옮겼더니 다시 망치가 됐다.** 손잡이 자리를
  0.4px 옮기면 축소 격자에 다르게 걸려 **모양이 통째로 달라진다.** 자리도 후보를
  격자로 뽑아 눈으로 골라야 한다(STYLE_GUIDE 에 옮겼다).
- **손에 쥔 날을 크게 키웠더니 「이음」이 3px 로 튀었다.** 몸은 가만히 있었다 —
  도구 재질만 빼고 **거기 붙은 잉크 테두리는 몸으로 남겨서** 바운딩박스가 벌어진
  것이었다. `_tool_mask()` 로 계산을 한 곳에 모으고, 견주는 시트도 같은 방식으로
  빼도록 `_load_ref()` 를 만들었다.
- **`qa_player_sprite.gd` 에 캡처를 하나 더 붙이면서 무한 루프를 냈다** — "판이
  세워져 있으면 첫 단계"로 판단했더니 두 번째 판을 세운 순간 다시 첫 단계가 됐다.
  단계 번호(`_stage`)로 바꿨다.
- **일부러 고장 내서 검사가 무는지 확인했다**: 등록 안 한 PNG 를 넣기 / 도구 모션을
  칠하지 않기 / 자루와 날을 같은 색으로 만들기 — 셋 다 FAIL, 되돌린 뒤 다시 PASS.
- `qa_sprite_check.py`(22장) PASS. Godot 자체 QA 14개 전부 PASS
  (`qa_player_walk` / `qa_player_sprite` / `qa_inventory` / `qa_character_sprite` /
  `qa_uid_files` 포함). 캡처를 눈으로 확인했다 — 6배·12배·**실제 게임 배율 3배**
  (지형 풀색 위)와 인벤토리 창.
