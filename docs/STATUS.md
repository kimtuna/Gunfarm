## #8 의 무엇이 문제였고 검사가 뭘 잡았나

커밋된 #8 스프라이트에 검사기를 돌린 결과가 그대로 진단이었다:

```
FAIL 잉크아래   잉크(33)보다 어두운 램프: hair 16, pants 20, boot 11
FAIL 평균명도   90 (100~170 밖)
FAIL 어두운비율  24% > 22%
FAIL 채도      31 < 34 — 탁하다
```

- **원인은 "옷색 × 0.46 / × 0.26" 으로 바지·신발을 만든 것이다.** 곱셈이라 램프
  아래쪽이 잉크(명도 33) 밑으로 내려가 버려서, 바지와 신발이 색이 아니라 **구멍**으로
  읽혔다 — 이게 하반신이 한 덩어리로 뭉쳐 보인 진짜 이유다.
- 고친 뒤: 전부 `ok`, 평균명도 102, 어두운비율 14%, 채도 43,
  경계 명도차 shirt|pants 71 / pants|boot 38.

## 스스로 판단해서 고친 것

- **고정 밴드를 피부·머리에까지 씌우면 안 된다는 걸 도중에 잡아서 고쳤다.**
  이전 세션의 미커밋 코드가 재질마다 목표 명도를 못박는 방식이었는데(그 아이디어
  자체는 옳고 그대로 살렸다), 그대로 두면 **은발도 「가장 짙은」 피부도 전부 같은
  값으로 나와서 커스터마이징이 통째로 무의미해진다.** 색 조합 5개를 실제로 뽑아
  나란히 놓고 보다가 발견했다 — 검사기는 한 벌만 보므로 이걸 못 잡는다.
  지금은 옷 계열(셔츠→바지→신발)만 코드가 계단을 보장하고(`bands_for()`),
  피부·머리는 **하한만** 준다. DESIGN.md / STYLE_GUIDE 에 이유와 함께 적었다.
- **뒷모습 머리에 세로 결을 넣었다.** 대비를 올리자 뒷머리가 매끈한 회색 달걀
  (=민머리)로 보였다. 헤어라인을 물결지게 하는 쪽은 덤불이 돼서 버리고, 부위 id 만
  다른 같은 껍데기를 세로로 3줄 얹어 내부선이 결이 되게 했다.
- **`잉크아래`·`채도` 검사는 지시에 없던 항목인데 추가했다.** 지시의 "대비 문제"를
  실제로 일으킨 게 잉크보다 어두운 램프였고, "코어키퍼 쪽으로"라는 요구를 숫자로
  옮기면 채도가 되기 때문이다.

## 이전 세션의 미커밋 코드를 어떻게 했나

세션 시작 시 `game/tools/gen_character.py` 에 미커밋 변경이 있었다 — **램프 개편
(#9 범위)과 걷기(walk) 뼈대(#13 범위)가 한 파일에 섞여 있었다.** 램프 개편은 이번
항목에 그대로 필요해서 살려서 이어 고쳤다. 걷기 쪽은:

- `_body()` 가 `pose` 인자를 받도록 바뀐 리팩터가 램프 개편과 같은 커밋에 묶여 있어
  떼어내려면 `_body` 를 다시 써야 했다. 그래서 **살려뒀다.**
- **idle 출력에는 영향이 없다**(`phase=None` 이면 오프셋이 전부 0). "에러 없이
  도는가"까지만 확인했고(`sheet(...phase=i/6)` 6프레임 생성 성공), **걷기 시트는
  만들지 않았고 눈으로 보지도 않았다.**
- **#13 은 그대로 미완료다.** 걷기 진폭·위상 조정과 시각 QA 는 전부 #13 의 몫이다.
