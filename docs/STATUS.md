## 스스로 판단해서 고친 부분

- **#37 (5) 의 미정을 「누구나 열 수 있다」로 정했다.** 근거 셋을 `DESIGN.md` 에 적었다 —
  (1) 이 서버는 PvE 이고 **방 코드를 아는 사람만 들어오는 협동 방**이라 낯선 사람의
  약탈은 방 코드가 이미 막고 있다, (2) 막으면 **죽은 사람이 접속을 끊었을 때 파티원이
  짐을 지켜줄 방법이 아예 없어져서** 타이머가 그대로 아이템 소멸이 된다(「인벤토리
  안전」과 부딪힌다), (3) 파티원이 대신 주워다 주는 것은 PvE 협동에서 자연스럽다.
  **구현은 "상자에 주인을 안 적는 것"이라 코드가 한 줄도 안 늘었다.** PvP 섬을 만드는
  시점에 다시 보라는 단서도 같이 적었다.
- **여는 방법을 좌클릭으로 골랐다.** `DESIGN.md` 「조작」이 *"별도의 「상호작용 키」
  (예: F)는 두지 않는다"* 고 못 박아뒀으므로 새 키를 만들 수 없었다. **커서가 상자
  위에 있고 72(타일 1.5칸) 안에 서 있으면 그 클릭은 여는 클릭이고 도구로 안 간다** —
  우선순위를 상자에 준 이유는 반대로 하면 상자 위를 겨눈 좌클릭이 도끼질이 되어
  **상자를 영영 못 열기** 때문이다. 근거를 「조작」에 적었다.
- **데스드롭 상자는 꺼내기만 되는 상자로 만들었다**(넣는 길이 없다). 30분 뒤 내용물과
  함께 사라지는 상자에 물건을 넣게 두면 「인벤토리 안전」의 "조용히 사라지면 안 된다"와
  정면으로 부딪힌다. 「건축」의 설치형 상자는 타이머가 없으니 그쪽은 양방향일 것이다.
- **월드 설정에 「사라지지 않음」을 넣었다.** 이 설정을 둔 근거가 *"죽으면 짐을 잃는
  방식 자체를 불쾌해하는 사람이 많다 … 그 강도를 사람마다 정할 수 있어야 한다"* 인데
  강도의 한쪽 끝이 없으면 그 문장이 반만 지켜진다. 반대쪽 끝(5분)도 같이 넣었다.
- **바꾼 설정은 다음에 생기는 상자부터 적용된다**(이미 놓인 상자는 안 흔든다).
  「무제한 → 30분」처럼 남은 시간을 새로 지어내야 하는 경우가 생기고, 그러면 "내 상자가
  몇 분 남았는가"를 플레이어가 예측할 수 없게 된다.
- **빈 상자를 월드에 남기지 않는다** — 빈손으로 죽으면 아예 안 생기고 다 꺼내면 그
  자리에서 사라진다(그때 창도 같이 닫힌다). 찾아올 것이 없는 상자는 쓰레기다.
- **`inventory_panel.gd` 의 `draw_item()` 과 그 도우미 셋을 `static` 으로 바꿨다.**
  상자 창이 같은 함수를 부르게 하려는 것이다 — 베껴 쓰면 "같은 아이템이 창 안팎에서
  다르게 보이면 안 된다"가 두 곳으로 갈린다(`ground_item_node.gd` 가 이미 자리표시를
  베껴 쓰고 있어서 같은 실수를 늘리지 않았다).
- **`qa_health.gd` 가 빈손으로 시작하게 고쳤다.** 이제 죽으면 인벤토리가 상자로
  옮겨가서 **하단 핫바 그림이 죽기 전과 뒤가 달라지고**, 그 파일의 10번("되살아난
  화면이 스폰 화면과 같은가")이 체력·리스폰과 무관한 이유로 실패했다. 이유를 주석에
  적어뒀다 — 8번("다쳐도 새 HUD 가 안 생긴다")은 여전히 화면 전체를 본다.

## 어려움 / 에러와 해결

- 자체 QA **15가지 전부 PASS**(엔진 ERROR 0건). 이웃 검사도 전부 다시 돌렸다 —
  `qa_health` / `qa_inventory` / `qa_hotbar` / `qa_ground_items` / `qa_world_entry` /
  `qa_gun_ammo` / `qa_bullets` / `qa_map` / `qa_player_world` / `qa_settings` /
  `qa_slot_store` / `qa_world_gen` / `qa_main_menu` / `qa_character_slots` /
  `qa_uid_files` 전부 PASS.
- 캡처를 눈으로 확인했다 — 궤짝이 풀밭 위에 플레이어와 같은 도트 결로 서 있고,
  상자 창의 칸이 인벤토리 창과 똑같이 보이며(아이콘·수량·자리표시 전부), 모두
  가져가면 핫바가 죽기 전 그대로 돌아온다. 월드 설정 화면도 「설정」과 같은 결이다.
- **처음에 월드 설정 화면의 배경을 반투명(0.94)으로 뒀더니** 뒤의 일시정지 메뉴
  버튼들이 글자 사이로 비쳐서 읽기 어려웠다. 「설정」 화면이 이미 **불투명 배경**을
  쓰고 있어서 같은 값으로 맞췄다 — 겹쳐 띄우는 화면끼리 배경 처리가 갈리면 안 된다.
- 상자가 화면에 보이는지 픽셀로 볼 때, **상자 앞에 서면 플레이어가 상자를 가린다**
  (Y정렬상 앞이다). 자체 QA 는 상자 옆(오른쪽 56, 아래 20)에 세우고 궤짝 몸통의
  나무색(R>G)을 짚는다 — 쇠 띠와 자물쇠를 피한 자리다.
- **`docs/GOTCHAS.md` 는 119줄 그대로다** — 이번에 부딪힌 것 중 "Godot 이 이렇게
  동작한다"에 해당하는 새 사실이 없었다(캡처 전 대기, `InputEventAction` 으로 클릭
  흘려보내기, `warp_mouse` 는 전부 이미 적혀 있는 함정이고 그대로 따랐다).
  **150줄 상한까지 여유가 줄고 있다는 메모는 계속 유효하다.**
