## 만든 것

- **코어는 노드가 아닌 순수 클래스 넷이다.** `item_types.gd`(아이템 종류 표) /
  `item_stack.gd`(한 칸에 든 뭉치) / `inventory.gd`(칸 18+9, 옮기기·넣기) /
  `ground_items.gd`(바닥에 놓인 것 — 이번엔 데이터 자리만). 화면은
  `inventory_screen.gd`(띄우기·마우스)와 `inventory_panel.gd`(그리기·칸 자리)뿐이고,
  **무엇이 어디로 가는지는 한 줄도 화면 쪽에 없다** — 나중에 서버가 같은 코어를 부른다.
- **「인벤토리 안전」을 반환값의 모양으로 못박았다.** 넣는 길은 `take_in(뭉치)` 하나이고,
  **넣은 만큼만 그 뭉치에서 덜어낸다** — 못 넣은 몫은 호출한 쪽의 뭉치(= 바닥/출력
  버퍼/상자에 있는 바로 그 물건)에 그대로 남는다. 반환값을 무시해도 아이템이 사라질
  수가 없는 모양이다. 편의용 `add()` 는 남은 수량을 돌려준다.
- **저장은 슬롯의 `inventory` 자리**(탐험 기록 옆, 캐릭터마다 따로). 아이템마다 소유
  상태(`own`: `local`)를 지금 넣어뒀다 — 나중에 넣으면 세이브가 깨진다.
- **키는 `world.gd` 한 곳**: E 열고닫기, 숫자키 1~9(창이 닫혀 있어도 먹는다),
  Esc 는 설정 → 인벤토리 → 지도 → 일시정지 순으로 가장 안쪽부터.
- 검증은 `game/qa/qa_inventory.gd` — 캡처는 `60_inventory_open` / `61_hotbar_9` /
  `62_inventory_drag` / `63_after_drop` / `64_reloaded`.

## 스스로 판단해서 고친 부분

- **드래그가 아이템을 인벤토리에서 빼지 않게 했다.** 흔한 방식(집으면 손에 들고 있다가
  놓을 때 넣기)은 끌던 중에 창이 닫히거나 예외가 나면 그 물건이 아무 데도 없는 상태가
  된다 — 「인벤토리 안전」과 정면으로 부딪힌다. 지금은 **집은 칸을 흐리게 그리고 마우스
  자리에 같은 그림을 하나 더 그릴 뿐**이고, 실제 이동은 놓는 순간 코어의 `move()`
  한 번이다.
- **아이템 종류를 DESIGN.md 가 이름을 적어둔 것만 넣었다**(27종). 장비 칸을 실제로
  넣고 빼보려면 장비 아이템이 하나는 있어야 하는데, 지어내는 대신 「새 테크 라인」이
  이미 이름을 적어둔 **가방**을 썼다(효과 없음 — 칸에 들어가기만 한다).
- **한 칸 최대 수량(도구·장비 1, 나머지 99)은 DESIGN.md 에 없어서 이번에 정하고 적었다.**
  "겹치기 쌓임"을 검사하려면 한도가 있어야 한다.
- **자체 QA 가 실제 마우스로 끈다**(`Input.warp_mouse` + 버튼 이벤트). 함수를 직접
  부르면 이번에 만든 "화면 좌표 → 어느 칸인가" 변환을 정작 안 지나간다. 커서가 정말
  그 자리에 갔는지도 매번 확인한다 — 안 그러면 창 크기/배율이 어긋났을 때 엉뚱한 칸을
  짚으면서 조용히 통과한다.

## 어려움 / 에러와 해결

- **일부러 열 군데를 고장 내서 전부 FAIL 나는 것을 확인했다**(남은 몫 버리기 / 장비 칸이
  아무거나 받기 / 창이 열려도 입력 안 끊기 / Esc 가 인벤토리 건너뛰기 / 슬롯에 저장
  안 하기 / 버릴 때 인벤토리에서 안 빼기 / 숫자키 무시 / 핫바 10칸 / 창 밖 놓기 무시 /
  드래그가 코어를 안 부르기). 열 개 모두 잡혔고, 원본으로 되돌린 뒤 다시 PASS.
- **끌고 있는 그림이 원본 칸 위에 겹쳐 찍혀서 "안 그려진 것"처럼 보였다.** 캡처 자리를
  칸이 하나도 없는 빈 자리로 옮기니 마우스를 따라오는 것이 바로 보였다 — 겹치는 그림을
  눈으로 확인할 때는 배경이 비어 있는 자리에서 찍을 것.
- **핫바 번호(1~9)를 아이템보다 먼저 그려서 아이템이 덮어버렸다.** 캡처를 보고 알았다 —
  칸이 56px 이라 번호를 피해 놓을 자리가 없으므로 아이템 **다음에** 그림자와 함께 그린다.
- `qa_inventory` PASS, `qa_world_entry` / `qa_map` / `qa_player_world` / `qa_slot_store` /
  `qa_uid_files` 모두 PASS. 캡처 5장을 눈으로 확인했다.
