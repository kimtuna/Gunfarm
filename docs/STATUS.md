## 이번에 한 번 실패했다가 고친 것 (다음 바퀴가 다시 밟지 않게)

첫 구현은 **자체 QA 를 전부 통과했는데 화면으로 보니 불합격**이었다 — 시드를 바꿔도
똑같이 생긴 밋밋한 원형 섬만 나왔다. 노이즈 배율이 거리 감쇠에 비해 너무 작아서 감쇠가
지형을 지배한 탓이다. 수치(바다 비율)만 보면 오히려 "시드마다 46~48% 로 안정적"이라
좋아 보였다는 게 함정이다. 지금은 "해안선 복잡도"(바다에 닿은 땅 칸 / 전체 땅 칸)를
QA 합격 기준에 넣어서 다시 그렇게 되면 잡히게 해뒀다.

## 겹친 세션 / 내가 안 만든 변경 (사람이 볼 것)

세션 시작 시 작업 트리는 깨끗했는데, 작업 중에 **내가 건드리지 않은 파일들이 수정된
상태로 나타났다**: `ctl.sh`(caffeinate 로 감싸기), `loop.sh`(완료 항목 정규식이 날짜
접두사를 삼키도록 수정), `docs/index.html`, `scripts/render_dashboard.py`. 전부 하네스
쪽 개선으로 보이고 내 작업과 겹치지 않아서 **그대로 두고 커밋하지 않았다** — 사람이
확인해서 커밋할 것.

`game/project.godot` 도 같이 덮어써져 있었다(주석이 전부 날아가고
`window/stretch/aspect="keep"` 줄이 사라짐). 런타임 값을 찍어보니 `aspect` 는 여전히
`keep` 이라 **동작은 그대로**였지만(Godot 4 의 기본값이 `keep` 이라 같은 값이면 저장을
생략한다), PvP 공정성 규칙의 근거 주석이 통째로 사라지는 건 위험해서 `git checkout` 으로
되돌려뒀다. `--headless --import` 와 비-headless `--script` 실행으로 재현을 시도했지만
둘 다 다시 덮어쓰지 않았다 — 세션 시작 전부터 떠 있던 **Godot 에디터 프로세스**가
범인일 가능성이 높다(원인을 확정 못 했으므로 GOTCHAS.md 에는 적지 않았다).
