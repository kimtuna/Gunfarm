  • 도구의 2단계 — 실제 효과 (벌목 / 채광 / 사냥 / 낚시 / 밭일구기). 도구 1단계(그림과 모션)는 INBOX #24~#31 로 끝나지만, 좌클릭이 실제로 무언가를 바꾸는 것은 캘 대상이 월드에 생긴 뒤다. `DESIGN.md` 「새 도구를 추가하는 절차」의 2단계 — 도구가 아니라 대상을 기준으로 묶인다: 나무를 만드는 바퀴가 벌목까지, 광맥을 만드는 바퀴가 채광까지 같이 붙인다. 그래서 다음에 필요한 것은 도구 항목이 아니라 자원 오브젝트를 월드에 놓는 항목이다.
  • 밭 시스템(농사) — 괭이·물뿌리개가 실제로 쓸 밭 타일 상태(일궈짐 / 물 준 상태 / 마름)와 작물 성장. 규칙은 `DESIGN.md` 「생활 스킬 — 생산 계열」에 스타듀식으로 정해뒀고, 작물별 성장 일수·계절 제한은 아직 범위 밖이다.
  • 플레이어 체력 + 죽음 + 리스폰 + 데스드롭 상자 — 규칙은 `DESIGN.md` 「체력 / 죽음 / 리스폰」에 2026-09-07 로 다 정해져 있다(체력 100 / 스폰 좌표 리스폰 / 상자 30분 / 열면 타이머 멈춤). 먼저 있어야 하는 것: 플레이어가 데미지를 받을 경로 — 즉 총알(투사체)이 실제로 날아가고 맞는 것. 그게 없으면 죽을 방법이 없어서 검증이 안 된다. 순서는 총알 → 체력·죽음 → 데스드롭 상자다.
  • 침대 — 설치하면 리스폰 지점이 바뀐다(`DESIGN.md` 「건축 / 방 시스템」). 건축 시스템 자체가 아직 없으므로 그것과 같이 온다.
  • 월드 설정 화면 — 지금 「설정」에는 그래픽 옵션만 있다. 월드(슬롯)에 저장되는 설정을 두는 자리이고, 첫 항목은 데스드롭 상자 타이머다. 데스드롭 상자를 만드는 바퀴가 같이 만드는 게 자연스럽다.
  • 낚시 던지기(2단계) — 좌클릭으로 던지고, 거리는 마우스 커서까지로 조절하며(최소는 바로 앞, 최대는 화면 안), 찌가 떨어진 칸이 물이어야 낚시가 시작된다. 규칙은 `DESIGN.md` 「생활 스킬 — 채집 계열」의 낚시 항목에 다 있다. 정해야 할 것: 최대 거리 수치, 찌를 던지고 무는 것을 기다리는 시간, 무엇이 잡히는지.
  • 물의 종류(서식지) — 지금 지형은 땅/바다 2종뿐이라 서식지를 나눌 기준이 없다. 민물·깊은 바다·동굴 물 같은 구분이 생겨야 "서식지에 따라 잡히는 물고기가 다르다"가 성립한다. 물고기 종류를 먼저 만들지 말 것 — 나눌 기준 없이 종류만 늘리면 전부 같은 물에서 나온다. 지형 확장 → 서식지 → 물고기 순이다.
