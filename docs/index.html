  • #1 [BUILD] 메인 메뉴 화면: 플레이 / 설정 / 나가기 세 버튼. "나가기"는 실제로 앱을 종료하고, "플레이"와 "설정"은 아직 빈 화면으로 이동만 한다(각각 #2, #3에서 채운다). 프로젝트 진입 씬을 이 메인 메뉴로 바꾼다.
  • #2 [BUILD] 캐릭터 슬롯 화면(코어키퍼 스타일 3개 슬롯). 빈 슬롯을 고르면 캐릭터 커스터마이징 화면으로, 캐릭터가 있는 슬롯을 고르면 월드 입장으로 넘어가는 자리만 만든다(커스터마이징 항목과 월드 생성 자체는 범위 밖 — DESIGN.md "범위 밖 / 아직 미정" 참고). 슬롯 데이터는 `user://` 저장/불러오기로 유지된다.
  • #3 [BUILD] 설정 화면의 해상도 옵션. **해상도를 바꿔도 카메라가 보여주는 월드 범위는 모든 해상도에서 동일해야 한다**(DESIGN.md "카메라 / 해상도" PvP 공정성 규칙). 서로 다른 해상도 2개 이상에서 실제로 같은 월드 범위가 보이는지 스크린샷으로 검증할 것.
